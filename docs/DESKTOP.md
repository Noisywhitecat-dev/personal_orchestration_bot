# Windows desktop app

## 가장 간단한 실행 방법

`AI Orchestrator-0.1.0-x64.exe`를 더블 클릭합니다. 별도 터미널이나 Node.js 실행 명령은
필요하지 않습니다. 처음에는 파일을 바꾸지 않는 **체험 모드**로 열립니다.

1. 왼쪽의 **프로젝트 등록**에서 이름을 입력합니다.
2. **폴더 선택**을 눌러 작업할 Git 프로젝트를 고릅니다.
3. **프로젝트 추가**를 누릅니다.
4. 가운데 대화창에 원하는 작업을 적고 **보내기**를 누릅니다.
5. Claude 역할의 계획을 확인하고 **승인**을 누릅니다.

체험 모드는 흐름만 보여주며 실제 파일과 AI 토큰을 사용하지 않습니다.

## 실제 Claude와 Codex 연결

1. Claude Code와 Codex가 먼저 설치되고 로그인되어 있어야 합니다.
2. 왼쪽 아래 **앱 설정**을 엽니다.
3. Claude와 Codex를 각각 **실제 AI**로 바꿉니다.
4. 실행 파일이 PATH에 있으면 기본 `claude`, `codex` 값을 그대로 사용합니다.
5. 찾지 못하면 **찾기** 버튼으로 각각의 `.exe`를 선택합니다.
6. 필요하면 목록에서 모델과 노력치를 지정합니다. 비워 두면 각 CLI의 기본값을 그대로
   사용합니다.
7. **저장하고 다시 시작**을 누릅니다.

버튼을 누르면 앱 창은 그대로 유지되고 내장 서버만 다시 시작된 뒤 새 설정으로 화면이
자동 연결됩니다. 새 설정으로 서버를 시작하지 못하면 이전 설정으로 되돌리고 이유를
표시합니다. 따라서 설정 파일을 직접 찾아 고칠 필요가 없습니다. 앱을 두 번 실행해도 기존
창 하나만 사용합니다.

Codex 모델 목록과 지원 노력치는 설치된 Codex CLI의 모델 캐시에서 읽습니다. 캐시를 읽을 수
없을 때만 앱에 포함된 검증 목록을 사용합니다. Claude 목록은 Claude Code 공식 모델 호환표를
따릅니다. 모델을 선택하면 그 모델이 실제로 지원하는 노력치만 표시되며, 저장할 때도 호환되지
않는 조합은 제거됩니다. 각 모델 아래에는 CLI 기본값과 일반 개발 권장값, 작업 난이도별 참고
설명이 표시됩니다. 노력치가 높을수록 복잡한 작업의 품질이 좋아질 수 있지만 시간과 토큰
사용량도 늘어납니다. 모델 자체의 계정 사용 가능 여부는 각 서비스 구독에 따라 다릅니다.

화면의 버튼, 작업 상태, 사용량, 진행 기록과 Windows 상단 메뉴는 모두 한글로 표시됩니다.
AI가 직접 작성하는 계획·리뷰·오류 내용의 언어는 연결된 AI의 응답에 따라 달라질 수 있습니다.

실제 AI 모드는 등록한 프로젝트 파일을 변경하고 토큰을 사용합니다. 처음에는 반드시
백업되었거나 버려도 되는 깨끗한 Git 저장소에서 시험하십시오.

## 데이터 위치

설정과 작업 기록은 실행 파일 옆이 아니라 Windows 사용자 애플리케이션 데이터 폴더에
저장됩니다. portable EXE를 다른 폴더로 옮겨도 기록은 유지됩니다.

## 개발자가 실행 파일 만들기

```powershell
npm install
npm run desktop:dist
```

완성된 단일 실행 파일은 `app-release` 폴더에 만들어집니다. 설치형 패키지가 필요하면
`npm run desktop:installer`를 사용합니다.
