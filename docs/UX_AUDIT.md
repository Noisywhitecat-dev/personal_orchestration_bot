## 검증 근거

- 메모리/SQLite: 실행 중·승인 대기 삭제 차단, 완료 작업 삭제, 다른 작업과 프로젝트 보존.
- SQLite: 중간 오류를 주입해 메시지·사용량·실행을 포함한 롤백 검증.
- HTTP: 명시적 확인, 교차 origin 차단, 중단 후 삭제, 삭제 후 404.
- SSE 공개 이벤트, 삭제 후 선택 복구 및 마지막 작업 삭제 시 빈 화면 데이터 복구.
- React 정적 렌더링: 상태별 삭제 버튼, 확인창 기본 취소 포커스·이스케이프, 사이드바 실제 모델/노력치와 미보고 한도.
- Electron lifecycle 대역 + 실제 Fake 서버: 안내 완료가 서버를 유지하며 모델 설정 저장은 재시작함을 확인.

## 이번 검증에서 남은 항목

격리한 Fake 서버와 사용량/desktop bridge 대역을 준비했지만 브라우저 도구가 로컬 URL을
net::ERR_BLOCKED_BY_CLIENT로 차단했다. 이번 변경의 실제 클릭·키보드·스크롤·반응형 레이아웃은
검증 완료로 간주하지 않는다. 이전 M18 화면 검증 결과를 이번 변경의 증거로 대체하지 않는다.
실제 AI 생성 호출과 실제 계정 조회는 실행하지 않았다. 운영 DB·외부 프로젝트·전역 설정은 변경하지 않았다.

후속 화면 확인: 삭제 확인 취소/삭제 후 선택, 작업·프로젝트 왕복 초안, 설정창 왕복 편집 보존,
IME/Ctrl+Enter, 긴 대화 스크롤, 520px/데스크톱 창에서 사이드바와 실행 버튼, 콘솔 오류 확인.
